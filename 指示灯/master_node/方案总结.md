# 应急指示灯系统 — 优化方案总结

> 基于 ESP32 (ESP-IDF 5.5) + NimBLE + LED Matrix + LTE MQTT + Mesh

---

## 一、清理无用组件

### 删除 hub75 组件

- **原因**：`hub75` 是旧版 LED 矩阵驱动，已在 `main.cpp` 中被 `LED_Matrix` 组件替代，未被任何代码引用
- **操作**：删除 `components/hub75/` 目录及所有文件
- **影响**：无，清理项目冗余

---

## 二、BLE Beacon 集成

### 2.1 组件依赖

| 文件 | 修改内容 |
|------|----------|
| `main/CMakeLists.txt` | `REQUIRES` 末尾添加 `BLE_Beacon` |
| `components/BLE_Beacon/CMakeLists.txt` | `REQUIRES nvs_flash bt`（已有） |

### 2.2 头文件引用

```cpp
#include "ble_beacon.h"   // main.cpp 第 31 行
```

### 2.3 初始化代码

在 `app_main()` 中，LED Matrix 初始化之后、LTE MQTT 初始化之前插入：

```cpp
/* NVS 默认配置 (首次烧录后注释掉此行) */
Write_Nvs_Defaults();

/* BLE Beacon 初始化 (纯广播, 不连接) */
{
    static const BleBeacon_Cfg_t beaconCfg = {
        .uuid = {0xE0, 0xC5, 0xE6, 0xD8, 0x12, 0x34, 0x56, 0x78,
                 0x9A, 0xBC, 0xDE, 0xF0, 0x12, 0x34, 0x56, 0x78},
        .tx_power = (int8_t)0xC5
    };
    esp_err_t bleRet = Ble_Beacon_Init(&beaconCfg);
    if (bleRet != ESP_OK)
    {
        ESP_LOGW(TAG, "BLE Beacon 初始化失败, 继续运行");
    }
}
```

### 2.4 修复重复 app_main

- **问题**：`main.cpp` 中存在两个 `app_main` 函数（一个不完整的 BLE-only 版本 + 原始完整版本），导致编译冲突
- **修复**：删除不完整的 BLE-only `app_main`，将 BLE Beacon 初始化整合到原始 `app_main` 中

## 四、IRAM 溢出修复

### 问题

```
ld.exe: region `iram0_0_seg' overflowed by 3768 bytes
```

启用 NimBLE 后，BLE 控制器代码与 WiFi 控制器等现有代码争夺 IRAM 空间，导致溢出。

### 修复措施

#### 措施 1：缩减 BLE 控制器连接数

| 配置项 | 改前 | 改后 |
|-------|------|------|
| `CONFIG_BTDM_CTRL_BLE_MAX_CONN` | `3` | `1` |
| `CONFIG_BTDM_CTRL_BLE_MAX_CONN_EFF` | `3` | `1` |
| `CONFIG_BTDM_CONTROLLER_BLE_MAX_CONN` | `3` | `1`（旧版兼容） |
| `CONFIG_BTDM_CONTROLLER_BLE_MAX_CONN_EFF` | `3` | `1`（旧版兼容） |

#### 措施 2：关闭不必要的 BLE 控制器功能

| 配置项 | 改前 | 改后 | 说明 |
|-------|------|------|------|
| `CONFIG_BTDM_CTRL_FULL_SCAN_SUPPORTED` | `y` | `n` | 纯广播不需要完整扫描 |
| `CONFIG_BTDM_CONTROLLER_FULL_SCAN_SUPPORTED` | `y` | `n` | 旧版兼容同步 |
| `CONFIG_BTDM_BLE_ADV_REPORT_FLOW_CTRL_SUPP` | `y` | `n` | 纯广播不需要报告流控 |
| `CONFIG_BLE_ADV_REPORT_FLOW_CONTROL_SUPPORTED` | `y` | `n` | 旧版兼容同步 |
| `CONFIG_BTDM_BLE_CHAN_ASS_EN` | `y` | `n` | 关闭信道评估（连接用） |
| `CONFIG_BTDM_BLE_PING_EN` | `y` | `n` | 关闭 BLE Ping（连接用） |

#### 措施 3：扩展 IRAM 空间（关键修复）

| 配置项 | 改前 | 改后 | 效果 |
|-------|------|------|------|
| `CONFIG_ESP_SYSTEM_ESP32_SRAM1_REGION_AS_IRAM` | `n` | `y` | **增加 64KB IRAM 空间** |

**原理**：ESP32 的 SRAM1（64KB）默认用作指令缓存。项目未使用 PSRAM，不需要这么大缓存，将其重新映射为 IRAM，总 IRAM 从约 192KB 增加到 256KB。

## 五、应用启动流程

```
app_main()
├── nvs_flash_init()              // NVS 初始化
├── bsp_init()                    // 板级初始化
├── I2C 初始化 + 扫描             // 传感器总线
├── DHT20 初始化                  // 温湿度传感器
├── ENS160 初始化                 // 空气质量传感器
├── LED Matrix 初始化             // 应急指示灯矩阵
│   └── init_eiceg()
├── Write_Nvs_Defaults()          // 首次烧录写入 NVS 默认值
├── Ble_Beacon_Init()             // 启动 BLE iBeacon 广播
├── LTE MQTT 初始化               // 4G 远程通信
├── WiFi/Mesh 初始化              // 局域网通信
└── 创建任务
    ├── sensor_task               // 传感器数据采集
    ├── comm_task                 // 通信处理
    └── animation_task            // 动画显示
```

| 优化项 | 节省 |
|-------|------|

| **总计** | **IRAM 不再溢出，SRAM 多出 ~31 KB** |
