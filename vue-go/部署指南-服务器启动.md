> 项目目录：`/home/ubuntu/escape-project`

## 一、连接服务器

建议配置 SSH 密钥后使用：

```bash
ssh ubuntu@42.193.218.29
```

## 二、服务组成

服务器当前由以下部分组成：

| 服务 | 启动方式 | 端口 |
|------|----------|------|
| EMQX | Docker Compose | 1883、8083、8084、18083 |
| MySQL | Docker Compose | 3306 |
| Redis | Docker Compose | 6379 |
| InfluxDB | Docker Compose | 8086 |
| Go 后端 | Docker Compose | 8080 |
| FastAPI 算法 | Docker Compose | 8090 |
| Vue 前端 | tmux + Vite | 5173 |

## 三、启动全部服务

```bash
cd /home/ubuntu/escape-project
docker compose up -d
```

该命令会同时启动后端和 `algorithm-service`，不需要再使用 `nohup python3 main.py`。

启动前端：

```bash
tmux new -d -s frontend \
  "cd /home/ubuntu/escape-project/aiot/aiot-vue && npm run dev -- --host 0.0.0.0 --port 5173 > /tmp/frontend.log 2>&1"
```

## 五、发布后端

Dockerfile 直接复制预编译的 `aiot-server`，修改 Go 代码后需要先编译再重建容器。

```bash
# 本地或其他构建机
cd vue-go/aiot/aiot-v2
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -o aiot-server .
```

上传 `aiot-server` 到服务器后：

```bash
cd /home/ubuntu/escape-project
docker compose build aiot-backend
docker compose up -d aiot-backend
```

修改算法代码后：

```bash
cd /home/ubuntu/escape-project
docker compose build algorithm-service
docker compose up -d algorithm-service
```

## 六、常见检查命令

```bash
# 容器状态
docker compose ps

# 后端日志
docker logs aiot-backend --tail 100

# 算法日志
docker logs algorithm-service --tail 100

# 算法健康检查
curl http://127.0.0.1:8090/health

# 前端状态
curl -I http://127.0.0.1:5173/
tmux ls
cat /tmp/frontend.log

# MySQL 节点数量
docker exec mysql mysql -uroot -paiot123456 -N \
  -e "SELECT floor_id, COUNT(*) FROM aiot.graph_node GROUP BY floor_id;"

# 检查 BLE 映射
docker exec mysql mysql -uroot -paiot123456 -N \
  -e "SELECT COUNT(*), SUM(major IS NOT NULL AND minor IS NOT NULL) FROM aiot.graph_node;"
```

## 七、服务器重启后恢复

```bash
# 1. 启动 Docker 服务
cd /home/ubuntu/escape-project
docker compose up -d

# 2. 启动前端
tmux new -d -s frontend \
  "cd /home/ubuntu/escape-project/aiot/aiot-vue && npm run dev -- --host 0.0.0.0 --port 5173 > /tmp/frontend.log 2>&1"

# 3. 验证
docker compose ps
curl http://127.0.0.1:8090/health
curl -I http://127.0.0.1:5173/
```

## 八、注意事项

- 前后端接口路径统一使用 `/api/ceiling_lights`。
- BLE 定位接口是 `/api/location`，不是 `/api/ble-location`。
- 前端使用 Vite dev server，服务器重启后 tmux 会话不会自动恢复。
- 生产环境建议将前端改为静态构建并由 Nginx 托管。
