# 逃生系统云服务器部署指南

> 适用版本：当前 `vue-go/` 前后端、算法服务与 Docker Compose 配置
> 当前正式环境：`42.193.218.29`

## 一、前置条件

1. Linux 云服务器，建议 2 核 4 GB 及以上。
2. 已安装 Docker Engine 和 Docker Compose Plugin。
3. 已安装 Node.js、npm 和 tmux。
4. 已有 MySQL、Redis、InfluxDB、EMQX 和 Go 后端所需的 Docker 镜像或网络访问能力。

当前服务器项目目录：

```text
/home/ubuntu/escape-project
```

## 二、端口规划

| 端口 | 协议 | 用途 | 对外 |
|------|------|------|------|
| `22` | TCP | SSH | 是 |
| `1883` | TCP | MQTT TCP | 是 |
| `8083` | TCP | MQTT WebSocket | 视客户端需要 |
| `8084` | TCP | MQTT WebSocket TLS | 是 |
| `8080` | TCP | Go 后端 API | 是 |
| `8090` | TCP | Python 算法服务 | 可仅本机访问 |
| `5173` | TCP | Vue 前端 | 是 |
| `18083` | TCP | EMQX Dashboard | 建议限制来源 |
| `3306` | TCP | MySQL | 建议仅内网 |
| `6379` | TCP | Redis | 建议仅内网 |
| `8086` | TCP | InfluxDB | 建议仅内网 |

## 三、部署代码

将 `vue-go` 中的下列内容部署到服务器项目目录：

```text
docker-compose.yml
aiot/aiot-v2/
aiot/aiot-vue/
aiot/algorithm-service/
```

服务器目录结构应与本地一致：

```text
escape-project/
├── docker-compose.yml
└── aiot/
    ├── aiot-v2/
    ├── aiot-vue/
    └── algorithm-service/
```

## 四、构建 Linux 后端二进制

`aiot-v2/Dockerfile` 使用预编译的 `aiot-server`，必须在 Linux/amd64 可执行环境中构建。

```bash
cd vue-go/aiot/aiot-v2

CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -o aiot-server .
```

上传后确认文件具有执行权限：

```bash
chmod +x /home/ubuntu/escape-project/aiot/aiot-v2/aiot-server
```

## 五、启动 Docker 服务

```bash
cd /home/ubuntu/escape-project
docker compose build
docker compose up -d
```

Compose 会启动：

- `emqx`
- `mysql`
- `redis`
- `influxdb`
- `aiot-backend`
- `algorithm-service`

查看状态：

```bash
docker compose ps
```

## 六、启动前端

前端当前使用 Vite dev server 和 tmux：

```bash
tmux new -d -s frontend \
  "cd /home/ubuntu/escape-project/aiot/aiot-vue && npm run dev -- --host 0.0.0.0 --port 5173 > /tmp/frontend.log 2>&1"
```

确认启动：

```bash
tmux ls
cat /tmp/frontend.log
curl -I http://127.0.0.1:5173/
```

## 七、数据库初始化与迁移

首次初始化脚本：

```text
aiot/aiot-v2/manifest/deploy/sql/aiot.sql
aiot/aiot-v2/manifest/deploy/sql/graph.sql
```

Compose 中挂载到 MySQL 初始化目录，仅在空数据卷首次启动时生效。

服务器已经存在数据卷时，需要手动执行迁移：

```bash
docker exec -i mysql mysql -uroot -paiot123456 aiot < \
  /home/ubuntu/escape-project/aiot/aiot-v2/manifest/deploy/sql/ble_major_minor_migration.sql
```

验证 BLE 映射：

```bash
docker exec mysql mysql -uroot -paiot123456 -N \
  -e "SELECT COUNT(*), SUM(major IS NOT NULL AND minor IS NOT NULL) FROM aiot.graph_node;"
```

## 八、服务验证

```bash
# 算法服务
curl http://127.0.0.1:8090/health

# 后端路由
curl -sS -X POST http://127.0.0.1:8080/api/location \
  -H 'Content-Type: application/json' \
  -d '{"openid":"deploy-check","beacons":[]}'

# 前端
curl -I http://127.0.0.1:5173/

# 容器日志
docker logs aiot-backend --tail 100
docker logs algorithm-service --tail 100
```

空 BLE 请求预期返回：

```json
{
  "code": 51,
  "message": "beacons 不能为空",
  "data": null
}
```

## 十一、常见问题

### 后端容器仍运行旧代码

`aiot-server` 是预编译文件。只修改 Go 源码不会自动生效，必须重新编译并执行：

```bash
docker compose build aiot-backend
docker compose up -d aiot-backend
```

### 算法服务连接失败

确认后端配置中的地址为：

```yaml
algorithm:
  url: "http://127.0.0.1:8090"
```

并检查：

```bash
curl http://127.0.0.1:8090/health
```

### 前端打不开

检查安全组和 tmux：

```bash
tmux ls
cat /tmp/frontend.log
curl -I http://127.0.0.1:5173/
```

### BLE 定位无匹配节点

检查 `graph_node.major/minor` 是否与固件广播值一致：

```sql
SELECT node_key, floor_id, major, minor
FROM graph_node
WHERE status = 1
ORDER BY major, minor;
```

固件代码不在 `vue-go/` 内维护。相关 ESP32 工程和蓝牙广播方案位于仓库根目录的 `New_version_of_emergency/`。
